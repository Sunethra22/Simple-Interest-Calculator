# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned on a principal amount based on the annual rate of interest and the time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest
- Time period in years

## Output
The program calculates and displays the simple interest based on the values entered by the user.

## Technologies Used
- Bash scripting
- Linux command line

## How to Run
1. Open a terminal.
2. Navigate to the directory containing `simple-interest.sh`.
3. Run the script using:

   `bash simple-interest.sh`

4. Enter the principal amount, rate of interest, and time period when prompted.
5. View the calculated simple interest.

## Project Objective
The objective of this project is to practice Bash scripting, user input, arithmetic calculations, and basic command-line operations.
